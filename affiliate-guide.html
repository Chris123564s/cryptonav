佣金：50% 交易手续费分成 Cookie：90天 最低提现：100 USDT 结算：每月10号

五、替换 projects.json 中的占位符

注册完成并获得真实推广链接后，按以下方式替换 projects.json 中的占位符。

当前占位符状态（8 个 CEX 使用 "Cryptonav" 占位符）：

// 当前（占位符）： "binance": { "referral": "https://www.binance.com/en/register?ref=Cryptonav" } "okx": { "referral": "https://www.okx.com/join/Cryptonav" } "bybit": { "referral": "https://www.bybit.com/register?ref=Cryptonav" } "coinbase":{ "referral": "https://www.coinbase.com/join/Cryptonav" } "kraken": { "referral": "https://www.kraken.com/signup?ref=Cryptonav" } "gate-io": { "referral": "https://www.gate.io/signup/Cryptonav" } "bitget": { "referral": "https://www.bitget.com/referral/Cryptonav" } "mexc": { "referral": "https://www.mexc.com/register?refCode=Cryptonav" } // 注册后替换为真实推广码（示例）： "binance": { "referral": "https://www.binance.com/en/register?ref=38294716" } "coinbase":{ "referral": "https://www.coinbase.com/join/7kx3 9m" } "mexc": { "referral": "https://www.mexc.com/register?refCode=1qR9Px" }
