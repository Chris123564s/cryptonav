## 5. 全站诊断 + 竞品分析 + 突围方案（产出 `CryptoNav-网站诊断与流量突围方案.md`）

### 实测发现（全部可复现，不是主观感受）

**内容结构**
- 46 页 / 38,038 词 / **中位 584 词** —— 低于 2026-06 核心更新后的「150 页主题深度」红线
  （该更新后 <150 页单主题站出现类目级崩塌，200-2000 页中型站掉 40-70%，权威站 +15-35%）
- **9 个分类页只有 279-392 词**（商业意图最强的钱页最薄），而 8 篇 learn 文章
  1405-1548 词（最没商业价值的内容最厚）——**内容投入与商业价值完全倒挂**
- **一手经验信号 0/46 页** —— YMYL 领域最致命。有一手经验信号 +38% 可见度，
  纯 listicle -63%

**技术**
- `cf-cache-status: DYNAMIC`，HTML **从不走 CDN 缓存**（连测 3 次）
  - 根因（Cloudflare 官方原文）：「一旦 Pages 项目加了 Functions，**默认所有请求都会调用
    Function**」。项目有 5 个 Functions 却没有 `_routes.json`
  - 已补 `public/_routes.json`（`include:["/api/*"]`）+ `public/_headers`，commit `5c5b60a`
  - **线上响应头仍未变化**，需在面板 Caching → Cache Rules 手动加一条
- 链页 **4 词/KB**（250-312KB HTML 承载 ~1100 词）；home 132KB
- header 14.9KB / **52 个链接**，占 learn 整页 32%（桌面+移动两套导航都写进 HTML）
- `auto.CcLMyVVA.js`（Chart.js）204KB 打进首页首屏

**SEO 基础面**
- **内链图完全平的**：46 个页面每一个都链向全部 9 个分类（header 硬编码），
  无 hub-and-spoke，权重无法集中；`/chain/ton` 内链数为 0
- 9 个 title >65 字符（SERP 截断）、6 个 <25 字符；5 个页面共用 Layout 默认 description
- robots.txt 是 **Cloudflare 托管版**，屏蔽了 GPTBot / ClaudeBot / Google-Extended /
  CCBot / Applebot-Extended / Bytespider（**战略取舍，待用户决策**）

### 竞品格局（关键洞察）

- **纯目录形态已被证伪**：DappRadar 2025-11 关停（7 年、2400 万 DAW、
  被机构引用，官方原话 "financially unsustainable"）。Cryptwerk 已腐化，
  唯一像样的直接对手是 CryptoLinks（单人运营，靠 **1,219 条骗局名单** 立身）
- **巨头不是靠写内容赢的**：DefiLlama / DexScreener 的自然流量几乎全是
  **品牌/导航词**，非品牌词接近零 —— 是**产品赢、SEO 收租**
- **唯一被验证的冷启动路径 = 可嵌入**：DefiLlama 头部外链来自 GitHub、
  Bitget 钱包、Morpho 官网、Tronscan；DexScreener 38K 引用域大量来自
  「每个代币页自动挂 View on DexScreener」。**可嵌入 = 外链飞轮**
- 巨头共同盲区：跨站对比、"best X for [场景]"、"Is X safe/rug/legit"、
  国别+监管、**任何需要编辑判断的内容**
- 行业正在集体失血：CoinGecko 43.5M→18.5M，CMC 157M→64M，Cointelegraph -99.9%，
  2025-09 前 77% 头部加密媒体失流

### 突围方案（一个主攻点，不铺七个方向）

**把「收录」升级为「核验」（Safety Verification）** —— 做第一个敢给判定结果的目录站。
8 个维度自动核验 63 个项目：域名年龄(WHOIS) / 合约是否可任意增发 / 蜜罐检测 /
审计情况 / 团队可验证性 / 历史安全事件 / 流动性深度 / 仿冒站检测。
产出 `/verify/[slug]` + Safety Score + 可嵌入徽章。

选它的四个理由（缺一不可）：
1. 巨头不敢做（定性判断有法律/商誉风险）→ 结构性缺口，不是暂时窗口
2. 真实搜索需求（"is X legit" 类高意图长尾）
3. 一次性解决两个致命伤：核验字段**就是专有数据**（被引用理由），
   核验过程**就是一手经验信号**（YMYL 的 E-E-A-T 门槛）
4. 可自动化，正好匹配已有的采集基建，边际成本极低

依赖顺序不能跳：核验数据 → 可嵌入徽章换外链 → 铺到 200+ 页 → 12-18 个月后谈流量

**立刻停止**：继续写通用百科内容。现有 8 篇 learn 文章在跟 CoinGecko Learn /
Kraken Learn / Coinbase Learn（DA 90+）抢词，必输，且占用了本该投入核验体系的产能。

### 时间预期（说真话）
- 6-12 个月起量不现实，**12-18 个月是基准**，且前提是 6 个月内走完上面那条链
- 核心更新受击后前 3 个月只改善 0-15%
- 含专有数据的内容被 AI 引用率 2 倍；**只改标题年份不改实质内容会被降权**
- 🔴 未找到任何可信的 2025-26 年"小团队 crypto 站 6-12 个月起量"公开案例
  （检索结果全是 SEO 代理商软文）
