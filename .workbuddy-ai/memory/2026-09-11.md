## 部署额度实测（重要）

联网核实：**Cloudflare Pages 免费版 = 500 次构建/月**。因为 `deploy-pages.yml` 是
"push 到 main 就构建"，所以 main 上的提交数 ≈ 构建数。用 GitHub API 数了过去 30 天：
**236 次 = 47%**。构成：**我 141 次（60%）**、数据机器人 93 次、用户 2 次。

→ **我的提交粒度是主要消耗源**，以后同一轮工作要合并提交，别再每个小步骤推一次。
→ 数据工作流是"有变化才推"，比理论值克制。
→ ⚠️ 若 Pages Git 集成还连着（用户一直没断），每次 push 构建两次 → **实际 ~94%，逼近上限**。
