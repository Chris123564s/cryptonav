## banner 视觉升级（commit `42a8116`）

用户："banner 视觉升级，当前已经是铺满了。" —— 铺满已解决，进入观感阶段。

**渐变改为 CSS 变量**：`--ad-1 / --ad-2 / --ad-glow` 三个值写在行内 style，
因为卡片需要两个端色 + 第三个更亮的高光色，只有 CSS 能一次带全。Tailwind 类做不到。

**层次**：基础渐变 + 两个模糊光斑 + 网格纹理（mask 渐隐）+ 内描边 + 暗角。
宽 banner 在 md+ 改**左右分栏**（文案左 / CTA 右），sidebar 和 inline 保持居中堆叠。

**几个不显然的点**：
- **描述文字在 <640px 隐藏**：120px 高的 banner 装不下「换行标题 + 描述 + 按钮」，
  `overflow-hidden` 会把句子拦腰截断 —— 丢掉比截断好。
- **直投和 promo 合并成一条渲染路径**：原本是两段几乎一样的代码，这正是
  「CTA 按钮只有 promo 卡有、付费位比免费位还空」的原因。
- **`.ad-label--on-media` 用双类选择器**（`.ad-label.ad-label--on-media`）：
  `.ad-container` / `.ad-label` 在 `@layer components`，那是 **Tailwind 的处理层、
  不是原生 cascade layer**，所以覆盖**不能靠加载顺序**，只能靠特异性。
  Astro 编译后是 `.ad-label[data-astro-cid-x].ad-label--on-media`（0,3,0）＞ 全局 `.ad-label`（0,1,0）。
- **渐变按页去重**：首页原本 bybit / binance / okx 三个都是 `exchange`（金），
  两个侧栏上下相邻像同一条广告重复。现改为 橙 / 金 / 靛蓝 / 蓝。
- 所有动效都在 `prefers-reduced-motion` 下关闭。

构建验证：渲染数 **84 直投 / 45 promo / 0 占位**（与改造前完全一致，零回归）。
