### ⚠️ 本环境 git 限制：无法创建 remote-tracking refs（别再浪费时间修）
- 现象：整个 `refs/remotes/` 命名空间不存在（`.git/refs/remotes/origin/` 目录都没有），`origin/main` 解析不了；但 `FETCH_HEAD` 内容是正确的。
- **三种写法全部无效**（都已实测）：
  1. `git fetch origin main`（带 refspec → 只写 FETCH_HEAD，本就不更新 remote-tracking，属预期行为）；
  2. `git fetch origin`（默认 refspec，终端打印 `* [new branch] main -> origin/main`，**但没真正落盘**）；
  3. `git update-ref refs/remotes/origin/main <sha>`（同样写不进去）。
- 结论：**本沙箱无法在 `.git/refs/` 下新建目录/文件**，是环境限制，**不是仓库损坏**，别再尝试修复、也别误判成对象库损坏去 reset。
- 影响：`git rev-list --count HEAD..origin/main` 和 `origin/main..HEAD` 这类同步检查**必定报 `ambiguous argument`**，以后不能用。
- **替代方案（以后一律用这个）**——用 `ls-remote` 直连远程取权威 tip：
  ```bash
  REMOTE=$(git ls-remote origin main | awk '{print $1}')
  LOCAL=$(git rev-parse HEAD)
  [ "$LOCAL" = "$REMOTE" ] && echo "IN SYNC" || echo "OUT OF SYNC"
  ```
- `git push` 不受影响（用显式 refspec 推），推送功能完全正常。
